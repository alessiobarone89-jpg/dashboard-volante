# Dashboard Volante

App per smartphone dell'operatore di volante: numerico di fine turno (37 voci), PDF della scheda, messaggio WhatsApp e calendario dei turni in quinta.

L'app non contiene dati: tutto quello che si inserisce resta solo sul telefono di chi la usa.

## Installare su iPhone
1. Apri il link dell'app con **Safari**.
2. Tocca **Condividi** (quadrato con la freccia verso l'alto).
3. Scegli **Aggiungi alla schermata Home**, poi **Aggiungi**.
4. Apri l'app dall'icona **Volante**: da quel momento funziona anche senza rete.

## Installare su Android
Apri il link con **Chrome**, menu con i tre puntini, **Installa app** oppure **Aggiungi a schermata Home**.

## Aggiornare
Sostituisci i file e, in `sw.js`, cambia `VERSIONE` (es. `volante-0.1.1`). I telefoni scaricano la nuova versione alla prima apertura con rete.
